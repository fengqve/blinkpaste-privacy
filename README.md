# BlinkPaste / 秒贴

把常用回复、地址、签名或提示词保存成片段，切换到秒贴键盘后点选插入，少翻一次备忘录。

Keep reusable replies and snippets at your iPhone keyboard.

**平台 / Platform:** iPhone

[App Store](https://apps.apple.com/app/id6783308653) · [开发者官网 / Developer website](https://woshichaojidashuaige.com/)
